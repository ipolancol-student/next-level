# Frontend de la tienda (Next.js)

Las instrucciones completas están en el [README principal](../README.md).

```bash
npm install
cp .env.example .env.local   # pon tu WP_URL
npm run dev                  # http://localhost:3000
```

| Comando | Acción |
|---|---|
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Compilar para producción (Vercel) |
| `npm run start` | Ejecutar la versión compilada |
| `npm run lint` | Revisar el código con ESLint |
